## 🎯 Vision
Exploration d'interfaces procédurales basées sur des modèles mathématiques.

> "Une étude sur le design génératif. L'interface utilise des fonctions de bruit de Perlin pour moduler dynamiquement l'UX selon des entrées biométriques simulées, testant l'adaptabilité organique du layout."
